# 🚀 Desafios JavaScript - Alura

Repositório com desafios práticos propostos durante o curso de JavaScript da Alura.

## 📋 Sobre o projeto

Cada desafio é um arquivo separado, focado em um conjunto específico de conceitos de JavaScript, seguindo a progressão do curso — de variáveis simples até estruturas de repetição.

### ✅ Desafio 02 — Prompt e Validação

### ✅ Desafio 03 — Condicionais e Template Strings
**5 exercícios sobre:** `if/else`, operador `||`, template strings

### ✅ Desafio 04 — Loops While

## 🚀 Como executar

1. Clone o repositório:

```bash
git clone https://github.com/viniasm19/desafios-javascript-alura.git
```

2. Abra qualquer arquivo `desafio-XX.js` no navegador via console, ou rode com Node:

```bash
node desafios-alura/desafio-01.js
```
